# 미국 성장주 모멘텀 퀀트 — 설계 스펙

> 작성 2026-07-05 · 상태: 승인됨(백테스트 검증 완료) · 대상: `quant/` 패키지

## 목적
한국 가치퀀트와 **동일 주기(수·토 15:00)로 함께 리밸런싱**되는 미국 성장주 모멘텀 퀀트. 초기자본 50백만(KRW). 가족 통합 플랜의 미국 슬리브를 시스템화.

## 전략 (백테스트로 확정)
- **유니버스**: 나스닥100 근사(~84종목, 하드코딩, 가끔 갱신)
- **팩터**: 12−1 모멘텀 = (52주 전 → 4주 전) 수익률
- **선택**: 모멘텀 상위 **10종목, 동일가중(10%)**
- **순위버퍼 20**: 기존 보유가 20위 밖으로 밀릴 때만 교체(회전율·비용 억제)
- **섹터 상한 4**(max_per_sector): 한 섹터 최대 4종목(=40%). 반도체 쏠림 방지(감내 −40%와 정렬). 섹터맵 하드코딩(us_config.yaml sectors). 미분류 종목은 실행 시 경고(상한 우회 방지).
- **주기**: 주간(수·토 신호)

### 섹터 상한 근거(백테스트)
무제한 CAGR35.9%·MDD−37.0%(평균 최대섹터 40%) → 섹터당4 CAGR32.9%·MDD−36.9%(최대섹터 35%). 상한은 수익 −3%p 대가로 극단 쏠림(현 스냅샷 90% 반도체)을 40%로 차단. 평균 리스크 개선은 작으나 "현 90%가 반도체 크래시를 만나는 꼬리 리스크"를 방어. 사용자 결정: 섹터당4.

### 검증 결과 (2009~2026, 890주, USD)
- 주간·버퍼20: CAGR +35.9%, Sharpe 1.25, MDD −37.0%(−40% 한도 내), 연회전 525%
- **세후(한국 해외주식세 22%)** CAGR +28.0% vs QQQ 매수보유 +18.5% → **+9.4%p 우위**
- ⚠️ 생존편향으로 절대수치 과대 → forward는 QQQ 대비 +2~5%p로 보수적 해석

## 구조 (한국 퀀트 패턴 미러링)
- `quant/us_config.yaml`: 유니버스·파라미터(n_hold=10, buffer=20, lookback=52, skip=4, cost, default_capital_krw)
- `quant/src/us_momentum.py`: 수집(yfinance 일별→W-FRI)·모멘텀·랭킹·선택·리밸런싱 트레이드 생성
- `quant/run.py` 신규 명령: `us-rank` / `us-rebalance` / `us-backtest`
- 상태: `quant/us_portfolio.yaml`(cash_krw·positions{ticker:shares}, gitignore)
- 리포트: `reports/quant/미국리밸런싱-YYYYMMDD.md`(USD·KRW 병기)
- 알림: 기존 `src/notify.py` 재사용(텔레그램)
- 통합: `weekly_rebalance.ps1`에 us-rebalance 추가 → 한·미 둘 다 발송

## 통화·실행
- 미국주식은 USD. 초기 50백만 KRW → 현재 환율(KRW=X)로 USD 환산해 사이징. 리포트 USD·KRW 병기.
- ⚠️ **실행은 신호·리포트까지만.** 현 매매연결(키움)은 한국 전용. 미국 실주문은 별도 브로커(IBKR 등) 필요 → 수동 체결. 자동주문은 향후 과제.

## 운영 방식 (한·미 동일)
- **신호(정보) 수신 = 주2회(수·토 15:00 텔레그램).** 수=집행 정렬용, 토=주말 점검용.
- **실제 리밸런싱 실행 = 사용자가 주1회 수동.** 시스템은 매매지시(신호)만 생성, 체결은 사용자.
- 백테스트가 주1회 리밸런싱 기준이라 이 운영과 정합. 순위버퍼(20)·밴드가 "필요할 때만 교체"를 보장.
